# 09. API на колонке и Telegram-бот

С 2026-10-26 API работает непосредственно на колонке. `station-api` — небольшой
статически собранный HTTP-сервер на порту `8787`. Он не опрашивает сеть и не требует
Python на устройстве. Все запросы требуют заголовок `X-Auth-Token`; токен хранится
только в `/data/opt/station-api.token` и на VPS в `/opt/tg-bot/station_token`.

| Метод | Путь | Тело | Действие |
|---|---|---|---|
| GET | `/api/v1/health` | — | проверка доступности |
| GET | `/api/v1/status` | — | актуальный режим, громкость, датчик, uptime |
| POST | `/api/v1/volume` | `{"value":40}` | установить громкость в своём режиме |
| POST | `/api/v1/volume/step` | `{"delta":10}` или `{"delta":-10}` | изменить текущую громкость относительно её значения на устройстве |
| POST | `/api/v1/mute` | `{"value":"on"}` или `{"value":"off"}` | mute |
| POST | `/api/v1/bluetooth` | `{"value":"on"}` или `{"value":"off"}` | включить/выключить Bluetooth-аудиоприёмник в своём режиме |
| POST | `/api/v1/mode` | `{"mode":"alice"}` или `{"mode":"custom"}` | переключить режим с перезагрузкой |

В режиме Алисы API не меняет громкость: ею управляет `maind`. После установки
громкости в своём режиме API сообщает новый уровень `volgest`. Демон синхронизирует
свою точку отсчёта и показывает уровень на LED-кольце около 1,5 секунды. Кнопки
Telegram-бота `+10/−10` используют `/api/v1/volume/step`, поэтому не зависят от
устаревшего показания громкости в меню.
После команды API считывает фактический уровень микшера: аппаратные ступени могут
округлить запрошенное значение на несколько процентов.

В своём режиме бот показывает отдельную кнопку Bluetooth. Она запускает встроенный
Linkplay A2DP-аудиоприёмник и включает видимость/подключение; после этого телефон
можно сопрячь с колонкой как с аудиоустройством. Выключение завершает Bluetooth-демон.
В режиме Алисы Bluetooth-кнопка скрыта.

Бот остаётся на VPS. Колонка сама поднимает исходящий SSH-туннель; на VPS API виден
только на `127.0.0.1:18787`. Выделенный пользователь `stationbridge` может открыть
только этот обратный порт, а бот обращается к нему по локальному адресу. Скрипт
`S99stationbridge` восстанавливает туннель после обрыва; `S96stationapi` запускает
локальный сервер при загрузке. Адрес VPS хранится на колонке отдельно в
`/data/opt/station-vps.addr` и не включён в репозиторий.

Старый Flask API и отправка отчётов на VPS сохранены как резервный вариант. Регулярный
`station-report.sh` отключён: его частые TLS-запросы раньше вызывали перезагрузки.
