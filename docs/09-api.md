# 09. REST API

Небольшой HTTP API на VPS (Flask за nginx) для управления колонкой без Telegram.
Авторизация — токен в query (`?t=...`) или заголовке `X-Auth-Token`.

## Эндпоинты

| Метод | Путь | Тело | Описание |
|---|---|---|---|
| GET | `/api/v1/health` | — | проверка живости |
| GET | `/api/v1/status` | — | полный статус колонки + запрошенные команды |
| POST | `/api/v1/mode` | `{"mode":"alice"\|"custom"}` | переключить режим |
| POST | `/api/v1/volume` | `{"value":0..100}` | громкость |
| POST | `/api/v1/mute` | `{"value":"on"\|"off"}` | mute |

Внутренние (для колонки, тот же токен):

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/report` | колонка присылает статус |
| GET | `/api/control` | колонка забирает команды |

## Как это работает

1. Колонка раз в **3 секунды** отправляет статус и забирает команды.
2. API складывает желаемые значения в файлы (`desired_mode`, `desired_volume`, `desired_mute`).
3. Колонка применяет их: громкость/mute — через `amixer`, режим — сменой `launch.json` и перезагрузкой.

## Задержка

- громкость/mute: до 3 секунд (один цикл опроса);
- смена режима: до 3 секунд на получение команды + 40–60 секунд на перезагрузку.

## Пример

```sh
TOKEN=...
curl -s "https://HOST/api/v1/status?t=$TOKEN"
curl -s -X POST -H 'Content-Type: application/json' \
     -d '{"value":40}' "https://HOST/api/v1/volume?t=$TOKEN"
```
