# 03. Сеть без maind

## Что выяснилось

`maind --platformd` управляет не только голосом, но и сетевыми сервисами (`networkd`, `wifid`).
Тем не менее, сам Wi-Fi держат отдельные демоны:

- `wpa_supplicant -B -c /vendor/wpa_supplicant.conf -iwlan0 -Dnl80211` — запускается init-скриптом;
- `dhcpcd -f /etc/dhcpcd.conf` — тоже отдельный сервис.

Если **не запускать лаунчер с задачами maind при загрузке**, сеть поднимается и работает: SSH и ADB доступны, колонка остаётся в сети, но без Алисы (нет LED, кнопок, голоса).

## Способ

1. `launch.json` с пустым списком задач:
   ```json
   { "nodes": [ { "name": "main", "root": ".", "tasks": [] } ] }
   ```
2. Сторож `/etc/init.d/S97maindguard`: через 60 секунд проверяет связь; если сети нет — восстанавливает `launch.json` и запускает лаунчер.

## Важные наблюдения

- Остановка `maind` **на работающей системе** может уронить Wi-Fi; запуск лаунчера обратно часто требует перезагрузки.
- Поэтому переход в maind-free режим делается **через перезагрузку** с пустым `launch.json`.
- Обратно — тоже перезагрузкой (или восстановлением `launch.json` + ребут).

## Восстановление

```sh
cp /data/local/tmp/backup_q/launch.json.current /system/vendor/quasar/launch.json
reboot
```
