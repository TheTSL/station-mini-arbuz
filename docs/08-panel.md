# 08. Панель и переключение режимов

## Идея

Колонка живёт в двух режимах:

- **alice** — штатный: `launch.json` с задачами `maind --platformd` и `maind --mediad` (голос, LED, жесты, сеть через `networkd`);
- **custom** — без `maind`: сеть держат `wpa_supplicant`/`dhcpcd`, звуком управляет свой плеер, жесты — свой демон.

Переключение делает сама колонка, панель только выставляет желаемый режим.

## Схема

```
колонка --(POST /api/report, токен)--> панель (Flask)
колонка <--(GET /api/control, токен)--- панель
```

1. Раз в 15 с колонка отправляет статус и спрашивает `desired` (alice/custom).
2. Если `desired` не совпадает с текущим режимом — колонка меняет `launch.json` и перезагружается.
3. Панель показывает фактический режим и запрошенный; после ребута они совпадают.

Защита от циклов: переключение не чаще раза в 4 минуты (`/tmp/last_switch`).

## Панель

Flask-приложение на `127.0.0.1`, наружу — через nginx с HTTP Basic auth. Обновление страницы — раз в секунду (fetch `/api/state`).

Показывает: модель, прошивку, режим, uptime, память, load, состояние `maind`, ADB/SSH, громкость, mute, Wi-Fi, температуру, состояние жест-демона и текущее расстояние с датчика.

Эндпоинты:

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/report?t=TOKEN` | приём статуса |
| GET | `/api/control?t=TOKEN` | желаемый режим для колонки |
| POST | `/api/mode?t=TOKEN` | смена режима (кнопки на странице) |
| GET | `/api/state` | данные для страницы |

`/api/report` и `/api/control` открыты без Basic auth (у них свой токен), страница и `/api/state` — за паролем.

## Init-скрипты на колонке

- `S98stationreport` — раз в 15 с запускает отправку статуса и проверку режима;
- `S97volgest` — в custom-режиме поднимает жест-демон (и останавливает его, если появился `maind`).

## Ограничения

- Переключение идёт через перезагрузку (40–60 с).
- Пока колонка перезагружается, панель показывает старый статус и «запрошено: …».
