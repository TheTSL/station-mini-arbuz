# 14. Текущее состояние и план

_Обновлено: 2026-10-26._

## Что работает

| Компонент | Состояние |
|---|---|
| Root: ADB 5555, SSH 2222 | работает, переживает ребут |
| Броня ADB, блок OTA | работает |
| Режим Алисы (maind) | работает, колонка стабильна |
| Свой режим (maind-free) | работает, переключение через панель/бота |
| Громкость в своём режиме | бот, API и датчик VL53L0; относительное управление после 350 мс наведения, захват до 60 см с проверкой дальнего сигнала относительно фона, ближний mute-жест отключён, перенос якоря на упоре 0/100% и 3 см защитного хода на краях, плавное изменение, удержание громкости при потере руки на 1 с |
| Звук: свой плеер | работает (stock alsa-lib) |
| Микрофоны PDM | работают без maind |
| LED-кольцо | управляется `maind`; в `maind-free` пробуется 10-сегментная шкала `volgest` с радужными цветами и красным на максимуме, кадр обновляется периодически |
| Громкость Алисы снаружи | нельзя: YandexIO зашифрован, нужна привязка |
| Отчёты на VPS | **выключены** — вызывают перезагрузки |

## Что выключено намеренно

- `S98stationreport` (отправка статуса) — периодические TLS-запросы приводили к зависанию
  `maind` и перезагрузке по вотчдогу (`docs/13-stability.md`).
- `S97volgest` (жест-демон) — запускается только в своём режиме (`maind-free`); сейчас проверен на устройстве.

Поэтому панель и бот показывают последние полученные данные (устаревают).

## Ближайшие шаги

1. **Лёгкий транспорт статуса**: plain HTTP (без TLS) на отдельном порту VPS + интервал 60 с;
   проверить стабильность 15–20 минут. Если снова ребуты — перейти на запрос по требованию.
2. **LED**: снять кадры `i2c_msg` коротким сеансом `i2cdump_ptrace` (2–3 с) в момент смены
   подсветки, затем воспроизвести в своём режиме.
3. **Громкость Алисы**: при желании — клиент YandexIO с привязкой (большой проект).

## Важные предупреждения

- Не держать `strace`/`ptrace` на `maind` дольше пары секунд — Алиса перестаёт отвечать.
- Не выставлять все 36 каналов LED на максимум — просадка питания и перезагрузка.
- Перед экспериментами с `launch.json` держать копию в `/data/local/tmp/backup_q/launch.alice.json`.
