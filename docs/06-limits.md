# 06. Ограничения и открытые вопросы

## Что не получилось

- **Полностью убрать Алису со звуком.** Без `maind` нет инициализации TDM/усилителя; сторонние ALSA-клиенты получают `ENOMEM` (пропатченная `libasound`). Обходится только статической stock alsa-lib и собственным плеером.
- **Одновременный AP+STA (репитер).** Драйвер `bcmdhd` формально поддерживает (`apsta=1`, `iw phy` разрешает AP+managed), но при создании `wlan1` клиентское подключение переносится на новый интерфейс, и `wlan0` остаётся без IP.
- **`dmix` для совместного звука с `maind`.** Ломает воспроизведение `maind` (треск/краш).
- **Замена wake-word на произвольное слово.** Требует модели в кастомном формате (см. `05-spotter.md`).

## Что проверено и работает

- Даунгрейд на `1.305.4.16` через локальный прокси с сертификатами.
- Постоянный ADB/SSH, броня от деактивации, блокировка OTA.
- maind-free режим с сетью.
- Захват микрофонов PDM (`arecord -D plughw:0,2 -f S16_LE -r 16000 -c 1`), реальный сигнал.
- Воспроизведение через собственный статический плеер на `hw:0,0` (S16_LE, 48k, 2ch).

## Полезное для продолжения

- Исходники драйверов Amlogic (`audiodsp`, `audioinfo`, `amaudio`) — в открытых ядрах 4.9.
- Драйвер `sound/soc/amlogic/auge/tdm.c` доступен в `khadas/linux` (ветка `buildroot-aml-4.9`).
- Конфиг ядра колонки: `/proc/config.gz` (4.9.68, `CONFIG_AMLOGIC_SND_SOC_MESON=y`).
