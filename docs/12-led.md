# 12. LED-кольцо

## Устройство

- В device tree узел `aml,ledring` (i2c-1, 0x1f, `aml_pca9557`), но драйвер не привязан; в ядре `CONFIG_AMLOGIC_LEDRING is not set`.
- На `i2c-0` по адресу `0x3c` — `ti,sn3236` (36-канальный LED-драйвер, только запись).
- `/sys/class/leds/` пуст.
- Кольцом управляет **`maind`**: держит `fd 29 → /dev/i2c-0`, линкует `libwmlighteffect.so`.
- `mv_ioguard` (потомок `rootApp`, стартует из `S05linkplay.sh`) держит `/dev/ttyS3` (линия к MCU),
  в нём уведомления `GNOTIFY=MCULED...` и UART-команды `AXX+...`.

## Что проверено

1. Прямая запись в `sn3236` пакетом в правильном порядке
   (36 байт PWM → `0x24` ток → `0x25=1` → `0x26=0` → `0x27=0`) даёт **кратковременную
   вспышку** кольца. Если писать ток/режим до PWM — эффекта нет.
2. Одиночные записи регистров не работают, нужна пакетная посылка.
3. Чтение регистров не поддерживается (`i2cget` → Read failed).
4. Записи в `ttyS3` от `mv_ioguard` во время wake-word нет — он не шлёт подсветку.
5. Остановка `rootApp`/`mv_ioguard` свет не удерживает.

## maind: как он пишет

- Обращение к чипу идёт через **`ioctl(fd 29, I2C_RDWR (0x0707), ...)`** — при wake-word
  зафиксировано **546 вызовов** за несколько секунд.
- `LD_PRELOAD` с перехватом `ioctl()` — не поймал.
- `LD_PRELOAD` с перехватом `syscall()` (raw `svc 0`) — тоже не поймал: `maind`, судя по всему,
  делает `svc` инлайн, минуя libc.
- `strace` показывает только номер ioctl, без данных.

## ptrace-дампер

Собран `i2cdump_ptrace.c` (ARM32, static): цепляется ко всем потокам `maind`,
ловит syscall-стопы, читает `i2c_msg` из памяти процесса. **Работает** — за 3 секунды
обработал 93 тысяч остановок и 28 тысяч ioctl.

Но: ptrace на всех 66 потоках **сильно тормозит `maind`** — Алиса перестаёт реагировать
на речь (проверено). Для снятия кадров нужен короткий сеанс в момент, когда кольцо уже
меняется, либо иной способ (логический анализатор на линии I²C).

## Вывод

Кольцо управляется `maind` по I²C; чтобы воспроизвести кадры в своём режиме, нужно
снять последовательность `i2c_msg`. Инструмент для этого есть, но его нельзя держать
включённым долго — `maind` чувствителен к ptrace.
